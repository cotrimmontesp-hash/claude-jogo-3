# Último de Pé

Battle royale visto de cima: 8 jogadores, o mapa encolhe e quem sobrar vence.

- Jogar no navegador: https://claude-jogo-3.vercel.app
- APK para Android: https://github.com/cotrimmontesp-hash/claude-jogo-3/releases/latest/download/UltimoDePe.apk

Controles: no celular, lado esquerdo anda e lado direito mira e atira. No PC, WASD + mouse, R recarrega, E troca de arma.
